# Multi-step Subscription Form

## Requirements

Create a responsive multi-step form that lets users configure a subscription and review their choices before confirming.

### Form flow

- Let users complete the form one step at a time.
- Let users return to previous steps and change their answers.
- Show a summary of the selected options before confirmation.
- Allow users to confirm their completed order.

### Validation

- Require all mandatory fields.
- Check that email addresses use a valid format.
- Require a selection when a step includes selectable options.
- Show clear validation messages when input is missing or invalid.

### Interface

- Adapt the layout for mobile and desktop screens.
- Provide visible hover and focus states for interactive elements.
